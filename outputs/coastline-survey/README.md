## 评估含义

六种岸段类型为岩板与巨石、沙石交界、混合岸线、海堤与护岸、栈桥与码头、防波堤与消波块。行程建议为优先踏勘、先查路线、先查边界、行程后置；它们反映接近和使用问题，不表示渔获概率。

可见结构、水下条件、公众通行与垂钓规则分别说明。候选鱼种和试钓思路是待验证的假设；人流也不能替代钓鱼压力数据。资料发布时间、影像拍摄日期、获取日期和评估日期各自保留，不把影像或公布资料当成实时现场状态。

## 文件与坐标

- classification.csv：17个分区与27处地点的统一分类表。
- yellowfin-evidence.csv：黄脚立11项来源证据表；yellowfin-field-log.csv为空白矶竿出钓记录表，yellowfin-seabream.json保留研究与钓法依据。
- human-fish-assessment.csv：27处候选完整评估表；artificial-structures.csv为海堤与港堤视图。
- baoan-estuary.csv：宝安河口七点评估；baoan-social-evidence.csv保留8条社交来源、作者、日期、读取范围和原帖链接；baoan-manifest.json保留22幅影像来源与范围。
- east-coast-assessment.csv：深圳湾东侧南向岸线8段完整评估；east-manifest.json保留25幅对应影像的来源与范围。
- shiyan-reservoir.csv及JSON：石岩周边10点评估及来源；shiyan-protection-map.png为官方附图第1页渲染，shiyan-protection-maps.pdf、shiyan-protection-table.pdf保存官方附件。附图公布于2025年11月10日，底图拍摄日期未知，鱼塘坐标尚未匹配法定边界。
- resolution.csv：70幅近景及细看的中心拍摄元数据和导出采样。
- analysis.json：完整中文结构化数据；human-fish-assessment.json与artificial-structures.json对应地点视图。
- survey.geojson：WGS84影像覆盖范围与近景参考中心，可导入GIS。
- 125幅原始卫星JPG、同名来源JSON、JGW及PRJ：总览、区域及地点的三种尺度导出；manifest文件保留完整来源与精确范围。

地点及观察岸段参考坐标采用WGS84，指向500米近景中心，可能位于水面，不是站立钓位。JGW和PRJ采用EPSG:3857，影像范围不是法定边界。图像像素间距是导出采样；更紧的裁切不增加原始地面细节。机器文件名用于索引，正式设施名称仍依各地点的确认状态判断。

具体入口、停车、当前公交班次、垂钓时段、保护边界及当天海况，按地点详情核查。调查未全面覆盖离岸岛屿和深汕特别合作区，部分图片包含香港或惠州岸线。
